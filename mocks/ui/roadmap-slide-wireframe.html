FDAI | Operating Model

하나의 운영 모델로
세 가지 거버넌스 결과를 만든다

FDAI는 SRE를 공통 운영 모델로 삼아, 복원력, 변경 안전, 비용 거버넌스를 같은 증거 기반 제어 루프로 운영합니다.

SRE 운영 모델 관찰 - 판단 - 승인 - 실행 - 검증 - 학습

Resilience

Chaos / DR

장애를 가정한 실험과 복구 훈련으로, 실제 복구 가능성과 RTO/RPO를 지속해서 검증합니다.

  • Chaos Engineering
  • Failover
  • Recovery drill

Change Safety

ARB + Change Management

변경 전에는 위험과 근거를 검토하고, 변경 후에는 효과와 롤백 가능성을 독립적으로 확인합니다.

  • ARB evidence
  • Policy gate
  • Rollback

Cost Governance

FinOps

비용 이상을 탐지하고, 신뢰성 제약을 지키는 범위에서 검증 가능한 최적화 후보를 관리합니다.

  • Cost visibility
  • Forecast
  • Verified savings
