Adoption boundary

FDAI already has prose, lists, tables, charts, code, citations, source details, action drafts, and a run record. This study adds only the response states that were not represented clearly enough.

How the Console chooses a response pattern

Natural language is interpreted once at the semantic boundary. Everything after that uses typed state and verified evidence shape, never browser keyword matching.

  1. 1InterpretTyped intent, target, scope, time, constraints, and requested format
  2. 2GateDisposition, authority, approval posture, and evidence availability
  3. 3ShapeScalar, records, trend, comparison, chronology, correlation, or matrix
  4. 4ComposeSmallest loss-bounded pattern plus exact-value fallback
  5. 5ValidateAllowed slots, bounded rows, evidence refs, locale, and channel capability
Typed conditionPrimary patternWhat the operator seesSafe fallback

Precedence: safety state first, then evidence posture, then semantic data shape, then explicit format preference, then saved preference, and finally channel reduction. A preference can choose among valid forms but cannot upgrade missing evidence or remove required safety sections.
