Usage, standard-price reference, and invoices

Measured usage counts provider-reported input and output tokens. This mock only contains synthetic examples of those fields. Model and workload allocation is illustrative, not observed billing attribution.

Standard-price reference cost requires published rates and their units, currency, and effective date. No rate snapshot is supplied here, so reference cost is unavailable. Token counts are not a currency amount.

Invoice amounts are not connected. Negotiated discounts, commitments, credits, taxes, exchange rates, and billing adjustments can differ from standard-price estimates. Reference cost is not invoice reconciliation.
