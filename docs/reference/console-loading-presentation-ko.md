# Console 로딩 표현

이 참조 문서는 FDAI Console 경로의 로딩 구조와 스타일시트 연속성을 정의합니다.

## 로딩 상태

모든 경로, 패널 및 범위가 제한된 내용 영역은 첫 로딩 프레임부터 골격을 렌더링합니다. 공통 골격은
스피너나 텍스트만 표시하는 대기를 대체하며, 경로는 최종 배치 크기를 유지하는 고유 형태를 제공할
수 있습니다.

대시보드는 자세 블록 다음에 메트릭, 분포, 주의 항목 및 버티컬 자리 표시자를 사용하므로 로딩
중에도 보고가 축소되지 않습니다. 하나의 화면 읽기 프로그램 상태가 로딩을 알리고 장식 블록은
숨깁니다. 동작 감소 설정에서는 shimmer가 멈추지만 정적 골격은 계속 표시됩니다.

공통 대체 경로는 제목, 요약 카드 및 본문 패널 자리 표시자를 사용합니다. 소유 경로 형태는 더
정확한 최종 배치를 유지할 때만 이 대체 경로를 대신합니다.

## 스타일시트 연속성

HTML 문서가 Console 스타일시트를 직접 의존하므로 인증, 경로, 컴포넌트 및 JavaScript hot
갱신 중에도 마운트된 SPA의 배치와 테마가 사라지지 않습니다. Vite는 같은 문서 링크를
fingerprint가 지정된 운영 CSS 자산으로 변환합니다.

개발에서는 hot-update 가드가 CSS 변경을 변환하기 전에 Vite의 경합 방지 파일 읽기 담당으로
처리합니다. 편집기의 일시적인 빈 스냅샷이 전체 스타일시트를 대체할 수 없습니다.
