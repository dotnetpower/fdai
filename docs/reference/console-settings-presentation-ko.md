# Console 설정 및 컴포넌트 표현

이 참조 문서는 FDAI Console 설정과 정적 시안의 공유 컨트롤, IAM 단계, 컴포넌트 문서화 및
권한 경계를 정의합니다.

## 공유 컨트롤

Console 설정과 정적 시안은 Calm Slate 컨트롤 토큰과 표현 프리미티브를 공유합니다. 데스크톱 폼은
34 px 표준 컨트롤과 28 px 간소 작업을 사용하며 터치 대상은 44 px입니다. 브라우저 로컬 환경 설정,
계정 환경 설정, 배포 정책, 근거 및 권한은 시각적으로 구분하되 영속성이나 권한 부여 계약은
변경하지 않습니다.

## 모델 설정 로딩

모델 작업 화면과 메뉴 사전 조회는 `GET /models/settings?view=summary`를 사용합니다.
Azure 모델 카탈로그를 검색하지 않고 기준 설정을 조회합니다. 기존 전체 GET도 유지합니다.
서술기와 웹 검색 저장도 역할, 리비전, 감사 검사를 바꾸지 않고 같은 요약 응답을 요청할 수
있습니다. 잘못된 화면 옵션은 변경 전에 차단하며, 저장 응답에도 인증된 관리 기능을 유지합니다.

카탈로그는 해당 작업 화면을 선택할 때 조회합니다. 로딩, 실패, 재시도 상태가 정상 설정이나
저장하지 않은 정책 초안을 덮어쓰지 않습니다. 설정된 계정을 확인한 뒤 모델, 배포, 할당량을
동시에 조회하며, 실패하면 나머지 요청을 취소합니다. 실제 관측 시각을 표시하고 추론 준비가
완료되었다고 추정하지 않습니다. 요약과 전체 응답은 클라이언트 메모리에서 각각 60초 동안
캐시하며, 변경이나 강제 갱신 후 두 캐시를 함께 무효화합니다.

선택한 작업 화면은 URL의 `model-view` 매개변수로 관리합니다. 반환된 카탈로그 전체를
검색하되 페이지마다 카드를 최대 12개 표시합니다. 조회할 수 없는 데이터를 관측된 0개로
표시하지 않습니다. 검토용 선택은 초안만 준비하며 모델을 배포, 호출, 활성화하지 않습니다.

## 설정 전반의 복구

비동기 저장 중에 추가한 편집 내용을 보존하고, 일부 저장과 검증된 재조회를 구분합니다.
로컬 필터는 적용 범위와 불러온 항목 수를 표시하되 서버 전체 개수를 만들어 내지 않습니다.
진단 조회는 독립적으로 완료되며 실제 완료 시각과 로컬 요청 시간을 표시합니다. 이 값은
서비스 수준 목표나 공급자 상태를 보장하지 않습니다.

메뉴별 전체 변경 사항은 [Console 설정 개선 목록](console-settings-review-ko.md)에 있습니다.

## IAM 표현

`/settings/iam`은 경로가 소유하는 이중 언어 메시지와 반응형 스타일을 사용합니다. 검증된 FDAI
Owner 역할과 테넌트 관리자를 구분하고, 요청, 검토, 보호된 적용 및 새 검증을 별도 단계로
표시하며 운영 할당 검토를 Agent oversight에 연결합니다.

Console과 Operator API의 점진적 업그레이드 중에는 안전한 역할 및 기능 사실을 유지하고 누락된
디렉터리 메타데이터는 알 수 없음으로 표시합니다. IAM 응답 디코더는 초기 Console 번들을 늘리지
않고 첫 IAM 요청과 함께 로드됩니다.

## 컴포넌트 갤러리

정적 컴포넌트 갤러리는 `mocks/ui/assets/component-registry.json`에서 문서화된 컴포넌트 계약을
읽습니다. 범위가 제한된 각 카테고리 화면은 시안을 먼저 표시한 뒤 소유자, 원본, 상태, 사용 지침,
반응형 동작, 접근성 계약 및 제품 참조를 제공합니다.

레지스트리가 없거나 잘못되면 시안을 정규 컴포넌트로 추론하지 않고 문서화 상태를 차단합니다.
갤러리는 합성 표현 근거로 유지되며 Console, Operator API 또는 실행기 권한을 부여하지 않습니다.
