# Azure Read Investigations implementation ledger

This delivery ledger preserves reviewable implementation scope, append-only transitions,
and resumable work while the roadmap owner remains focused on normative design.

## Implementation status

### Migrated implementation notes

> **Implementation status:** The optional adapter is implemented for exact-resource Resource Health
> only. The production wrapper remains disabled unless `FDAI_AZURE_MCP_ENABLED` is true. Other read
> tools continue through their typed provider or return explicit unavailable evidence.

> **Implementation status:** Production composition consumes the shared execution policy behind
> `POST /read-investigations`. Core owns direct and streamed execution through the PostgreSQL run
> and progress stores, while Operator owns authenticated replay and Web completion writeback.
> Bounded completion inbox retention is composed. Channel enqueue and governed runtime receipts
> remain open.
