# Document Ingestion and Drop Zone implementation ledger

This delivery ledger preserves reviewable implementation scope, append-only transitions,
and resumable work while the roadmap owner remains focused on normative design.

## Implementation status

### Implementation scope

| Area | State | Evidence | Notes |
|------|-------|----------|-------|
| Contracts, lifecycle, and bounds | implemented | service contracts; ingestion API and worker lifecycle tests | Shared records, bounded lifecycle transitions, retention, and access controls remain owned here. Format eligibility and extraction behavior moved to the focused format-policy owner. |
| Independent upload API and processing worker | implemented | `services/document-ingestion-api/`; `services/document-processing-worker/`; service-owned tests | Separate ASGI and worker packages implement scoped upload, processing, health, storage, event, and handover boundaries. |
| Governed automated RCA read binding | implemented | `delivery/persistence/postgres_governed_document_read.py`; `delivery/governed_rca_context.py`; Core service Terraform; focused governed RCA tests | Core accepts a separate read-only DSN secret and exact collection, access-reference, and reader-group configuration. Search filters before ranking and rechecks current metadata and group authorization before evidence admission. This does not validate a deployed document read. |
| PostgreSQL, ADLS, pgvector, Event Hubs, embeddings, and ClamAV bindings | in-progress | Independent service adapters; `infra/modules/storage/adls-gen2/`; `infra/local/docker-compose.yml` | Delivery implementations and local/deployed configuration exist, but this ledger does not have one governed exact-topology receipt covering every binding and failure boundary. |
| Rights management and revocation | implemented | protection adapters, durable reconciliation state, service migration, focused provider and restart tests | Production selects a digest-bound Purview/RMS-compatible inspector. Durable leased checks atomically disable the version and delete searchable chunks before retryable artifact cleanup. |
| Delegated authorization and preview | implemented | API protection adapter, preview service and route, focused authorization tests | Preview requires collection authorization, current active/available state, a provider decision bound to actor/document/digest/policy, and a bounded artifact whose digest and access descriptor still match. |
| Resumable upload and SharePoint synchronization | implemented | ADLS and SharePoint adapters; federated managed identity; PostgreSQL connector state; focused delta/download/retry tests | The FDAI-native connector owns cross-tenant Graph token exchange, delta, bounded download, deterministic upload identities, server-owned access policy, version binding, and legal-hold-aware deletion. Power Platform isn't a runtime dependency. |
| Measured scale | in-progress | `scripts/evaluation/document_ingestion_evidence.py`; focused evidence-tool tests | The content-free verifier requires the exact five-service topology, a reviewed non-sensitive corpus, every lifecycle/failure stage, and computes p50/p95 latency and queue delay, throughput, storage growth, and failure rate. An approved corpus receipt has not been recorded. |
| ACL-filtered hybrid document retrieval | implemented | `services/document-ingestion-api/src/fdai_ingestion_api_service/adapters/postgres.py`; focused document-search tests | One common authorized relation filters governed chunks by collection and access descriptor before bounded semantic and lexical ranking. Deterministic reciprocal-rank fusion changes no document visibility or execution authority. |
| Persistent collection document list | implemented | `GET /documents`; Console Documents route; focused API, Console, and browser tests | Refresh reloads the latest durable version per document for the selected logical collection. The list rechecks document access and does not create, rename, or move collection policy. |
| Governed document library actions | implemented | `download.py`; preview and deletion services; Console document library; focused API and browser tests | Collections render as policy-owned folders, lifecycle and index status stay separate, preview reuses delegated protection, unprotected source download audits before streaming, and deletion requires explicit confirmation plus server reauthorization. |
