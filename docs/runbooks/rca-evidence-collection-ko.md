# RCA 근거 수집 런북

근본 원인 분석(RCA) 가설을 수락하거나 게시하기 전에, 범위를 한정하고 출처를 인용할
수 있는 근거 집합을 구성할 때 이 런북을 사용합니다. 수집과 해석을 구분하여
모든 인과관계 주장을 알려진 출처와 시점으로 추적할 수 있게 합니다.

> 인시던트 범위 안에서 수집 권한이 부여된 근거만 수집하세요. 시크릿이나 접근이 제한된
> 원본 페이로드 대신, 내용이 드러나지 않는 참조와 해시를 저장합니다.

## 진입 기준

[인시던트 분류](incident-triage-ko.md)에서 인시던트 ID, 영향 범위, 책임 담당자,
근거 시간 범위, 다음 결정 기한을 정한 뒤 시작합니다. 범위 또는 시간 순서가
크게 변경되면 수집을 반복합니다.

## 역할과 수집 경계

| 항목 | 필요한 값 |
|------|-----------|
| 조사 책임자 | 범위, 예산, 최종 근거 집합을 책임지는 사람 |
| 검토자 | 출처 신원, 인용, 근거가 없는 부분을 검증하는 사람 |
| 시간 경계 | 필요한 사전 구간을 포함한 시작 및 종료 시각 |
| 리소스 경계 | 포함된 리소스, 의존성, 지역, 명시적 제외 대상 |
| 근거 예산 | 출처, 조회, 양, 보존 한도 |
| 접근 경계 | 권한이 부여된 신원과 취급 요구사항 |

수집 경계를 알리지 않고 확장하지 않습니다. 추가 리소스나 시간 범위를 조회하기
전에 변경된 경계를 기록하고 승인을 받습니다.

## 근거 인벤토리

| 근거 종류 | 수집할 내용 | 신뢰성 검사 |
|----------------|-------------|-------------------|
| 이벤트와 감사 | 감지된 문제, 상태 전이, 결정, 승인, 작업 | 생성 주체, 순서, 상관관계 ID, 해시 |
| 변경 | 배포, 구성, 카탈로그, 정책, 담당 체계 갱신 | 버전, 행위자, 범위, 완료 상태 |
| 메트릭 | SLI, 포화, 오류, 지연 시간, 의존성 상태 | 출처, 집계, 누락된 데이터, 시각 |
| 로그와 추적 | 상관관계로 연결된 실행 및 요청 기록 | 시계, 샘플링, 민감정보 제거, 추적 연속성 |
| 인벤토리 | 관련 시점의 리소스 상태와 관계 | 스냅샷 시간, 출처, 완전성 |
| 지식 | 규칙, 런북, 이전 인시던트, 아키텍처 참조 | 버전, 승인 상태, 출처 이력 |

해당 출처에서 기록을 생성했어야 하고, 출처의 정상 동작 여부를 확인해 기록의 부재가
유의미함을 입증한 경우에만 기록이 없다는 사실을 근거로 사용합니다.

## 수집 절차

1. **경계를 동결합니다.** 인시던트, 대상 리소스, 시간 범위, 출처 허용 목록,
	근거 예산, 접근 범위를 기록합니다.
2. **출처 상태를 수집합니다.** 반환된 데이터를 해석하기 전에 시계, 수집 지연,
	보존, 샘플링, 알려진 공백을 검증합니다.
3. **변경할 수 없는 참조를 수집합니다.** 상관관계로 연결된 이벤트, 변경, 메트릭, 로그,
	추적, 인벤토리, 규칙, 승인된 지식의 참조를 수집합니다.
4. **시간을 정규화합니다.** 출처 시각을 보존하고 알려진 시계 오프셋을 기록합니다.
	정렬을 강제하기 위해 시각을 다시 작성하지 않습니다.
5. **시간 순서를 구성합니다.** 원인의 우선순위를 매기기 전에 근거로 뒷받침되는
	사실을 시간순으로 정리합니다. 공백과 충돌하는 기록을 명시합니다.
6. **가설을 구성합니다.** 각 후보 원인에 대해 이를 뒷받침하는 근거와 반대되는 근거,
	주장을 반증할 관측을 기록합니다.
7. **인용을 검증합니다.** 모든 주장에 제공된 참조가 연결되고 수집
	경계 안에서 참조를 사용할 수 있었는지 확인합니다.
8. **집합을 검토합니다.** 검토자가 범위, 취급 방식, 최신성, 인용 무결성,
	대안, 해결되지 않은 모호함을 확인합니다.

## 가설 기록

주요 가설과 대안 가설에 동일한 필드를 사용합니다.

| 필드 | 내용 |
|-------|---------|
| 주장 | 범위가 한정된 인과관계 진술 하나입니다. |
| 뒷받침하는 근거 | 주장에 대한 확신도를 높이는 참조입니다. |
| 반대되는 근거 | 확신도를 낮추거나 대안을 뒷받침하는 참조입니다. |
| 반증 조건 | 주장을 반증할 수 있는 관측입니다. |
| 확신도 | 판단 근거가 포함된, 설정된 확신도 값입니다. |
| 공백 | 결론에 영향을 주는 누락되거나 신뢰할 수 없는 근거입니다. |

상관관계만으로 인과관계를 확정하지 않습니다. 인시던트 시작 시점과 가까운 변경은
작동 원리와 근거로 인과관계가 뒷받침될 때까지 후보로 유지합니다.

## 중지 조건

근거가 범위를 벗어나거나 인용을 검증할 수 없거나 시각이 일치하지 않거나
출처 상태를 알 수 없거나 프로바이더 응답에 신뢰성을 확인하지 못한 데이터가 포함될
수 있으면 중지합니다. 수집 과정에서 승인된 취급 범위를 벗어나 시크릿이나 접근이
제한된 페이로드가 노출될 수 있는 경우에도 중지합니다.

근거로 뒷받침되지 않는 결과는 미해결 가설로 사람에게 검토를 요청합니다.
실행 요건을 충족한 완화 방안으로 취급하지 않습니다.

## 근거 패키지와 감사

최종 패키지는 경계, 출처 인벤토리, 출처 상태 검사, 시간 순서, 근거
참조와 해시, 가설 기록, 검토자, 확신도 판단 근거, 해결되지 않은 공백을 포함합니다.
수집 시작 및 종료 시간을 기록하고 패키지 버전을 인시던트 감사 이력에 연결합니다.

## 완료 기준

모든 주요 주장에 검증 가능한 인용이 있고, 타당한 대안이 기록되며, 취급 규칙을
충족하고 검토자가 패키지를 수락하면 수집이 완료됩니다. 결과는 근거로 뒷받침되는
원인, 반증된 원인, 또는 해결되지 않았음을 명시한 결과일 수 있습니다.
