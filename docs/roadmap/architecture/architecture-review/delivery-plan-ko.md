# 온톨로지 기반 ARB 전달 계획

이 계획은 현재 매니페스트 중심 검토를 온톨로지 기반의 에이전트 소유 폐쇄 루프로 바꾸는 가장
작은 변경 순서를 정의합니다. 각 작업 패키지는 실행 가능한 종료 조건을 가지며 권한을 수반하는
변경은 기존 FDAI 게이트 뒤에 유지합니다.

> **시작 경계:** 구조 검사기, 일반 워크플로, Process 변환 결과, 읽기 전용 Console 화면은
> 존재합니다. 아직 자율적인 15개 에이전트 ARB 경로나 운영 근거 증명을 입증하지는 않습니다.
>
> **출시 경계:** 권한을 수반하는 결정 또는 실행 경로를 추가하기 전에 관찰 모드 수직 경로를
> 완료합니다.

## 한눈에 보는 설계

| 작업 패키지 | 결과 | 의존성 |
|-------------|------|--------|
| ARB-1 온톨로지 원본 | 최신 운영 의도, 토폴로지, 정확한 변경 개정을 조회할 수 있습니다. | 기존 온톨로지 플랫폼 |
| ARB-2 에이전트 근거 루프 | 관련 에이전트가 게시하고 Forseti가 검증된 근거를 결합합니다. | ARB-1 |
| ARB-3 결정 권한 | 변경할 수 없는 결정 증적이 사례, 근거, 조건, 승인을 결합합니다. | ARB-2 |
| ARB-4 효과 종료 | 결과 액션이 독립 관측과 복구를 통해 종료됩니다. | ARB-3 |
| ARB-5 학습 및 출시 | 반복 결과가 거버넌스 후보와 측정된 승격 근거를 만듭니다. | ARB-4 |

## ARB-1: 온톨로지 상태를 권위 있는 원본으로 만들기

이후의 모든 결정이 사용하는 운영 사실을 제공합니다.

- 배포에서 제공하는 `ServiceObjective`, `RecoveryObjective`, `CostObjective`,
  `ArchitectureConstraint`, `Ownership`, `ChangeWindow` 인스턴스를 변환합니다.
- 인증된 그래프 개정, 완전성, 최신성, 목적, 기준 시점 증적을 발급합니다.
- 정규화된 계획 `Change` 하나를 정확한 목표 상태 다이제스트와 계획 증적에 결합합니다.
- `config/architecture-review.yaml`을 변경 가능한 런타임 결정 상태가 아니라 검토 프로필로
  유지합니다.
- 검토 상태를 근거, 평가, 권한, 실행, 학습 축으로 모델링합니다.

**종료 조건:** 정확한 계획 변경 하나가 고정된 온톨로지 릴리스에서 시간 일관성이 있는 컨텍스트
스냅샷을 만듭니다. 평가는 타입 기반 그래프 증적을 함께 전달하고, 수락된 심각 또는 높음 차단
항목은 현재 유효한 위험 또는 예외 레코드를 유지합니다. 누락, 오래됨, 혼합 릴리스, 미검증,
잘림 상태의 컨텍스트는 권한을 낮추고 형식화된 이유를 제공합니다.

## ARB-2: 15개 에이전트 근거 루프 구성

ARB 에이전트를 추가하지 않고 기존 소유 경계를 연결합니다.

- Huginn은 변경할 수 없는 `Change`를 게시하고 Muninn은 개정과 컨텍스트를 보존합니다.
- 활성 목표와 의존 관계에서 Njord, Freyr, Loki, Heimdall을 선택합니다.
- 판단 전에 `OperationalEvidenceBundle`과 `OntologyScenarioBranch`를 구성합니다.
- 호출자가 제공한 워크플로 분기 결과를 에이전트 소유 토픽 근거로 대체합니다.
- Forseti가 기한이 있는 결합을 소유하고 `DecisionCase`와 `ImpactEnvelope`를 만듭니다.
- 적격한 목표 충돌만 Odin으로 보냅니다.
- Var 상향 전에 범위가 제한된 근거 재수집과 결정적 재평가를 시도합니다.

**종료 조건:** 완전한 저위험 fixture가 관찰 모드에서 자동 적합 권고안에 도달합니다. 오래됨,
충돌, 누락, 중복, 순서 변경, 지연 근거는 변경이나 조용한 손실 없이 명시적 보류에 도달합니다.

## ARB-3: 결정과 권한 결합

변경 가능한 상태 주장을 재현 가능한 권한 체인으로 대체합니다.

- 사례, 컨텍스트, 근거, 그래프, 카탈로그, 조건 다이제스트를 포함하도록 `Decision` 계약을
  버전 관리합니다.
- 승인 증적 식별자, 승인자 역할, 정족수, 자체 승인 금지, 만료를 결합합니다.
- 수락된 모든 심각 또는 높음 차단 항목에 완전한 위험 또는 예외 계약을 요구합니다.
- 주입된 공급자를 통해 근거 본문, 다이제스트, 범위, 개정, 최신성, 승인 권한을 검증합니다.
- 최종 증적에서 운영 준비 상태와 `ReviewCase` 변환 결과를 파생합니다.
- 수락된 제약 조건 또는 운영 전이를 별도의 거버넌스 ActionType으로 표현합니다.

**종료 조건:** 근거 항목, 승인, 조건, 대상 개정, 그래프 개정 중 하나가 바뀌면 이전 결정
식별자가 무효화됩니다. 매니페스트 편집이나 워크플로 컨텍스트 값은 운영 권한을 만들 수 없습니다.

## ARB-4: 효과를 독립적으로 종료

ARB를 제어 전용으로 유지하면서 승인된 작업을 일반 액션 파이프라인에 연결합니다.

- 모든 리소스 변경을 ActionType 승격, 정책, 위험, Var, Thor, Saga 경로로 다시 보냅니다.
- 선택된 옵션, 영향 묶음, 중지 조건, 롤백, 잠금, 멱등성, 예상 효과를 변경 없이 전달합니다.
- Heimdall이 권위 있는 관측으로 각 예상 효과를 종료합니다.
- 누락되거나 불완전한 관측은 성공으로 보고하지 않고 대기 상태로 둡니다.
- 실패 또는 중지 조건 발생 시 Vidar가 승인된 묶음 안에서 복구합니다.
- 조건 또는 보호 목표가 위반되면 검토를 다시 열거나 만료합니다.

**종료 조건:** 수락된 shadow 사례 하나가 `Change -> DecisionCase -> ImpactEnvelope ->
ActionRun -> ObservedOutcome`을 연결하고, 실패 fixture는 행위자가 자체 효과를 평가하지 않은 채
복구에 도달합니다.

## ARB-5: 안전하게 학습하고 승격

권한을 완화하지 않으면서 검토된 결과를 사용해 향후 사람 접점을 줄입니다.

- Muninn이 정확한 사례 이력과 결과 집단을 보존합니다.
- Norns는 범위가 제한되고 동의 조건을 충족한 근거에서만 비활성 `RuleCandidate`를 제안합니다.
- Mimir가 검토된 카탈로그 코드 경로로 다시 검증하고 승격합니다.
- 자동 적합성, 조건 종료, 근거 재수집, 사람 승인, 보류, 정책 이탈, 롤백, 결과 정산 완전성을
  측정합니다.
- 관찰 집단이 게이트를 충족한 범위가 제한된 검토 기능만 승격합니다.
- 기본 ActionType 권한을 바꾸지 않고 회귀 시 자동으로 강등합니다.

**종료 조건:** 고정된 관찰 집단이 정책 이탈 0건과 완전한 결정 및 효과 계보를 갖춘 독립 검토
승격 결정을 지원합니다.

## 첫 번째 수직 경로

Console 또는 운영 게이트를 확장하기 전에 다음 경로를 구현합니다.

```text
Huginn Change
-> Muninn context snapshot
-> OperationalEvidenceBundle
-> ontology scenario branch and diff
-> Forseti DecisionCase and ImpactEnvelope
-> observation-mode recommendation
-> Saga audit
-> derived ReviewCase projection
```

다음 조건을 충족하면 수직 경로가 완료됩니다.

- 같은 변경 개정은 변경할 수 없는 사례 하나를 만듭니다.
- 최신의 완전한 그래프는 자동 적합 권고안을 만들 수 있습니다.
- 오래됨, 잘림, 충돌, 대상 불일치 근거는 보류를 만듭니다.
- 보호 목표 위반 선택지는 Odin 중재 전에 제거됩니다.
- 근거 갱신은 같은 Process를 재개하고 같은 논리 사례를 재평가합니다.
- 어떤 단계도 소유 경계 밖에서 승인하거나 변경하거나 승격하거나 실행할 수 없습니다.

## 검증 매트릭스

| 경계 | 집중 입증 항목 |
|------|----------------|
| 온톨로지 | 정확한 릴리스, 경로 방향, 시간 기준 시점, 최신성, 완전성, 충돌, 잘림 |
| 토픽 | 단일 작성자, 중복, 순서 변경, 재시도, 역압, 배달 못한 편지, 재시작, 재현 |
| 판단 | 중재 전 강한 제약 조건, 무조치 기준선, 제한된 선택지, 결정적 식별자 |
| 승인 | 역할, 정족수, 자체 승인 금지, 시간 초과, 증적 재현 공격 저항 |
| 실행 | ARB 제어 전용, 별도 승격된 ActionType, 7개 안전장치 |
| 결과 | 독립 대상 관측, 모든 예상 효과 종료 또는 명시적 평가 불가 |
| 변환 결과 | 권위 있는 계보에서 파생된 읽기 모델, 만료 또는 제거된 근거 조정 |
| 지역화 | 영문 및 한글 구조, 링크, 번역 SHA, 용어, 문장 부호 |

## 목표가 아닌 항목

- 열여섯 번째 ARB 에이전트를 추가하지 않습니다.
- 워크플로가 에이전트를 직접 호출하거나 판단을 소유하게 하지 않습니다.
- 온톨로지 그래프가 승인하거나 실행하게 하지 않습니다.
- Bragi 또는 Odin을 범용 제어기로 만들지 않습니다.
- 아키텍처 기준선, 예외, 되돌릴 수 없는 변경, 운영 승격에 자동 권한을 부여하지 않습니다.
- 관찰 모드 수직 경로가 통과하기 전에 UI 개선이나 적용 모드 경로부터 시작하지 않습니다.
