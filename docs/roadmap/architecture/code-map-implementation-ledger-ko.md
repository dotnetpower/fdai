# 보관된 코드 맵 구현 원장

> **동결 보관:** 이 페이지는 코드 맵을 탐색 인덱스로 전환하면서 분리한 구현 원장을 보존합니다. 현재 구현 상태가 아니라 과거 근거입니다. 현재 상태는 연결된 각 소유 문서를 확인하세요.
