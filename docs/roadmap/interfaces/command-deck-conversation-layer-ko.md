# Command Deck 대화 표현 계층

이 문서는 Command Deck 대화 화면으로 옮길 수 있는 표현 계층과, 그 기준 사용처인 정적 시안을
정의합니다. 이 계층은 표현 전용이며 Console, Operator API 또는 실행기 권한을 부여하지 않습니다.

## 한눈에 보기

- `ui/calm-slate-deck-conversation.css`는 대화 화면으로 옮길 수 있는 표현 역할을 담습니다. 근거
  원본 준비 상태, 검색 추적, 인용, 근거 한계 안내, 출처 패널, 후속 질문, 입력창 맥락, 간결한 코드
  블록, 그리고 단계 표시줄과 관찰된 실행 타임라인, 모델 프로바이더 워터폴을 포함하는 실행 기록이
  여기에 속합니다.
- 정적 시안 `mocks/ui/deck-sources.html`(한 번에 답하는 형태)과 `mocks/ui/deck-adaptive.html`(적응형
  조사)이 기준 사용처입니다. 두 시안은 재생 엔진 `mocks/ui/assets/deck-sources.js`와 페이지
  스타일시트 `mocks/ui/assets/deck-study.css`를 함께 사용합니다. Console은 아직 이 계층을 가져오지
  않습니다.
- 공통 프리미티브를 재사용하는 규칙은 `.cs-deck-conversation` 아래로 한정하고,
  `console/src/shared-style-tokens.test.ts`가 이 계층을 추가 전용으로 유지하므로 가져와도 기존
  화면은 바뀌지 않습니다.

## 적용 방식

Console 적용은 덮어쓰기가 아닌 교체 이행입니다. 프리미티브 다음에 이 계층을 가져오고, deck
오버레이에 루트 역할을 추가하고, 소유 deck 컴포넌트에서 역할을 렌더링한 뒤, 대체된 기존
`.deck-*` 선언은 덮어쓰지 않고 삭제합니다.

## 재생 동작

이 시안은 준비 계획 전체를 대기 단계로 먼저 표시하고 각 단계의 결과는 그 단계가 실행된 뒤에만
보여 줍니다. 턴이 읽을 행 수에 맞춘 고정 창으로 출처를 읽고, 답변은 단어 단위로 스트리밍하면서
문장이 끝날 때마다 잠시 멈추며, 답변이 나타나기 전에 준비 패널을 접습니다.

대화 기록은 답변 중인 질문을 위쪽 가장자리 밖으로 밀어 올리지 않으면서 새 내용 쪽으로 부드럽게
이동합니다. 턴이 끝나면 검증 행이 보이는 위치까지 이동하고, 운영자가 직접 스크롤하면 즉시
따라가기를 멈추므로 읽고 있는 텍스트가 갑자기 움직이지 않습니다.

이 시안은 Console과 같이 모델 추적 캡처 여부를 턴마다 기록합니다. 실행 기록은 해당 턴에서
캡처가 켜져 있었고 설정이 여전히 켜져 있을 때만 요청, 시스템, 응답 다이제스트가 있는 모델
이벤트와 프로바이더 호출 행을 표시합니다. 설정을 켜더라도 캡처하지 않은 턴의 프로바이더
데이터는 드러나지 않습니다. 재생된 턴은 실행 기록의 합성 일정을 실제로 관찰한 단계 시각에
맞추므로, 기록된 소요 시간이 화면에 보인 과정과 일치합니다.

## 적응형 조사 형태

절차형 조사는 작업 과정을 접어 없애지 않고 대화 기록에 남깁니다. 밀도는
[작업 진행 계약](operator-console-progressive-conversations-ko.md#작업-진행-계약)이 정한 대로 타입
기반 궤적에서 정하며 답변 문장으로 정하지 않습니다. 시안은 다음 역할을 렌더링합니다.

- **계획.** 컴파일러가 세운 계획을 한 줄로, 그 계획이 설명하는 작업 위에 보여 줍니다.
- **웨이브.** 계획된 웨이브마다 한 행이 있고, 행마다 상태 표시가 하나 있습니다. 표시는 웨이브 번호,
  스피너, 결과 순으로 바뀝니다. 한 웨이브의 읽기는 병렬 레인으로 실행되며, 다음 웨이브는 현재
  웨이브가 끝난 뒤에만 시작합니다. 끝난 웨이브는 한 줄 요약으로 접혀서 다음 웨이브가 진행되는 동안
  대화 기록이 차분하게 유지됩니다. 결정론적 비교가 계획되어 있으면 마지막 행으로 이어집니다.
- **활동 카드.** 각 읽기는 라벨, 종류, 상태, 소요 시간을 보여 줍니다. 상세에는 작업, 권한 확인 결과,
  근거 권한, 실행 권한 없음, 대상 식별 정보, 도구를 보여 준 뒤, 타입 호출과 가려진 프로바이더 표현을
  간결한 코드 블록으로 보여 주고, 출력 또는 출력이 없는 이유를 보여 줍니다. 상세는 읽기가 끝난 뒤에만
  렌더링합니다.
- **작업 흐름 마일스톤.** 각 웨이브가 끝난 뒤의 결정론적 진행 사실입니다. 답변 텍스트와 다르게
  표시하며 근거 주장을 담지 않습니다.
- **한도.** 턴이 진행되는 동안에는 정책 한도를 보여 줍니다. 턴이 끝나면 서버가 보고한 최대치 대비
  사용량 계측으로 바꿉니다. 시안은 남은 예산을 실시간 막대로 그리지 않습니다.
- **맥락 영수증.** 적용된 운영자 선호를 접힌 영수증으로 보여 주며, 근거나 지시가 아닌 맥락이라고
  표시합니다.

답변은 발견 사항을 먼저 말하고, 사실 표, 확인 항목별 한 줄, 한계가 있으면 근거 한계 안내, 그리고
다음 안전 단계를 차례로 보여 줍니다. 중지하면 끝난 읽기는 모두 남기고, 실행 중인 읽기는 중지됨으로,
시작하지 않은 웨이브는 시작 안 함으로 표시하며, 답변은 작성하지 않습니다. 추천 후속 질문은 새 요청을
시작합니다.

시안의 조사 시나리오는 차이 없음, 차이 발견, 시간 초과된 읽기, 근거 충돌, 권한 거부, 같은 수준의
후보 사이 확인 질문, 오래된 맥락, 예산 소진을 다룹니다. 차이를 발견하면 초안을 만들지 않고 수정 초안
작성을 별도 요청으로 제안합니다. 시나리오는 `mocks/ui/fixtures/adaptive/`의 합성 궤적을 읽으며,
Console 계약 테스트도 같은 파일을 파싱합니다.

## 코드 블록

실행 기록의 페이로드는 컴포넌트 갤러리의 간결한 코드 형태를 사용합니다. 어두운 코드 배경,
Copy가 있는 언어 라벨, 문법 색상으로 구성됩니다. 색상은 `ui/calm-slate-tokens.css`의 공통
`--cs-code-*` 토큰에서 가져오며 갤러리도 같은 토큰을 읽습니다. Copy는 원문을 그대로 복사합니다.

## 화면 이동 동의

출처를 선택하면 대화를 벗어나지 않고 그 자리에서 출처 정보를 펼칩니다. 출처의 열기 동작과 근거
원본 표시줄을 포함해 다른 화면으로 이동하는 deck 링크는 모두 먼저 확인 대화 상자로 운영자에게
묻고, 동의한 경우에만 이동합니다. 페이지 안 앵커와 새 탭 클릭은 가로채지 않습니다.
