# Command Deck 대화 표현 계층

이 문서는 Command Deck 대화 화면으로 옮길 수 있는 표현 계층과, 그 기준 사용처인 하나의 정적
Command deck 시안을 정의합니다. 이 계층은 표현 전용이며 Console, Operator API 또는 실행기 권한을
부여하지 않습니다.

## 한눈에 보기

- `ui/calm-slate-deck-conversation.css`는 대화 화면으로 옮길 수 있는 표현 역할을 담습니다. 근거
  원본 준비 상태, 검색 추적, 인용, 근거 한계 안내, 출처 패널, 후속 질문, 입력창 맥락, 간결한 코드
  블록, 구조화된 답변 블록, 그리고 단계 표시줄과 관찰된 실행 타임라인, 모델 프로바이더 워터폴을
  포함하는 실행 기록이 여기에 속합니다.
- 기준 사용처는 `mocks/ui/deck.html`입니다. 하나의 Command deck 페이지가 모든 응답 형태를 같은 턴
  구조로 재생합니다. 재생 엔진 `mocks/ui/assets/deck-sources.js` 하나가 모든 형태를 렌더링합니다.
  인시던트, 변경, 메모리 형태와 답변 시나리오 두 개는 `mocks/ui/assets/deck-forms.js`에서 가져오고,
  페이지 스타일시트 `mocks/ui/assets/deck-study.css` 하나가 미리 보기 틀을 구성합니다. 답변 형태는
  [공통 답변 표시](operator-console-ko.md#공통-답변-표시)의 읽기 쉬운 배치를 사용합니다. 공통 답변
  렌더러 `mocks/ui/assets/deck-answer.ts`가 Console의 파서로 Markdown 답변과 타입이 있는 JSON 답변을
  렌더링하고, 미리 보기 제어는 편집한 Markdown이나 JSON을 렌더링합니다. Console Command Deck도
  [적용 방식](#적용-방식)에 설명한 대로 같은 계층을 가져옵니다.
- 이전 시안 주소인 `deck-sources.html`, `deck-adaptive.html`, `deck-sources-v2.html`,
  `incident-conversation.html`은 쿼리 매개변수를 유지한 채 `deck.html`의 해당 형태로 이동합니다.
  이 주소들은 자체 표현을 갖지 않습니다.
- 공통 프리미티브를 재사용하는 규칙은 `.cs-deck-conversation` 아래로 한정하고,
  `console/src/shared-style-tokens.test.ts`가 이 계층을 추가 전용으로 유지하므로 가져와도 루트
  역할을 렌더링하지 않는 화면은 바뀌지 않습니다.

## 적용 방식

Console 적용은 덮어쓰기가 아닌 교체 이행입니다. `console/src/styles.css`가 프리미티브 다음에 이
계층을 가져오고, deck 오버레이가 `cs-deck-conversation` 루트 역할을 가지며, 소유 deck 컴포넌트가
역할을 렌더링하고, 대체된 기존 `.deck-*` 선언은 덮어쓰지 않고 삭제했습니다. 기존 클래스 이름은
코드나 테스트가 조회하는 연결 지점으로만 남깁니다.

| Console 화면 | 렌더링하는 계층 역할 |
|--------------|----------------------|
| 근거 원본 준비 상태, 사용자 말풍선, 입력창 맥락, 후속 질문 | 준비 상태, 사용자 줄, 맥락 칩, 최신으로 이동, 후속 질문 역할 |
| 검색 추적 | 실시간 근거 패널, 단계와 출처 창, 답변 스켈레톤 |
| 근거 기반 답변 | 답변 상태, 인용과 인용 단어 묶음, 작업 행(주장 수가 있는 판정, 출처 버튼, 아이콘 도구), 출처 목록, 처리 과정 펼침, 작업 초안의 요청 카드 |
| 코드 | 답변 코드, JSON과 텍스트 페이로드, 생성된 코드 근거의 간결한 코드 형태. highlight.js 토큰 클래스는 공통 `--cs-code-*` 토큰을 사용합니다. |
| 실행 기록 | 기록 요약, 단계 표시줄, 실행 타임라인, 모델 프로바이더 워터폴 |
| 구조화된 표현과 문서 | 조립 정보 줄, 요약용 사실 격자, 한계용 근거 안내, 근거와 기록 행용 조용한 사실 목록, 접힌 블록과 정확한 값용 펼침, Markdown 문서와 검증된 문서 산출물용 문서 카드 |
| 조사 | 계획 역할을 쓰는 시작 줄, 첫 패널의 계획 상태와 완료 시점 한도, 맥락 영수증, 조용한 마일스톤 줄, 중지된 읽기 |
| 공통 답변 표시 | 출처를 여는 인용 버튼, 답변으로 돌아가기가 있고 계층의 출처 펼침으로 표시하는 답변 근거 행, 조용한 펼침에 담은 원본 Markdown, 근거 서비스 펼침 안의 준비 상태 줄 |

시안에 대응 부분이 없는 Console 영역은 구조를 유지하면서 이 계층의 상태 색상, 조용한 라벨, 12px
하한을 따릅니다. 실행 기록의 단계 상세, 신호, 실행 세부 정보, 관찰된 작업 조사 타임라인, 공통 답변
표시의 검증 상태 줄과 근거 서비스 요약, 표현 표와 차트가 여기에 해당합니다. 완료된 조사 패널은 작업이
완료되었으면 접히고, 실패했거나 일부만 완료되었거나 사용할 수 없었으면 펼친 상태로 남습니다. 운영 요약은 카드 안에 두지 않고 답변과 함께 이어지며, 중립이나 긍정 톤의
안내는 조용한 메모로 남깁니다. 주의가 필요한 것은 한계와 공백뿐이기 때문입니다. 요약 머리글, 기록된
상태 줄, 근거 상태 그룹, 단계에는 아직 타입 지정 표현 블록이 없으므로 Console은 이를 렌더링하지
않습니다. 조사는 웨이브 행 대신 관찰된 작업 목록을 유지합니다. `work_progress_shape` 고정 형태에는
웨이브 수와 계획된 조회 수만 있고 어느 조회가 어느 웨이브에 속하는지는 없기 때문입니다. Console은
[작업 진행 계약](operator-console-progressive-conversations-ko.md#작업-진행-계약)에 따라 이 고정
형태로 계획을 표시하고, 웨이브 사이의 멈춤에서 답변이 시작되지 않게 합니다.

## 응답 형태

미리 보기 제어에서 응답 형태와 그 형태의 시나리오 하나를 고릅니다. `?form=`과 `?scenario=`로 같은
상태를 바로 열 수 있습니다. 모든 형태는 같은 턴 구조를 사용합니다. 질문, 읽기 전용 준비 패널, 인용이
있는 답변, 구조화된 답변 블록, 검증 행, 출처 패널, 실행 기록, 후속 질문 순서입니다.

| 형태 | 시나리오 | 보여 주는 내용 |
|------|----------|----------------|
| 답변 | 근거 있음, 일부 근거, 원본 사용 불가, 근거 충돌, 수정됨, 검증 안 됨, 연결된 리소스 | 인용이 있는 한 번의 답변입니다. 검증 안 됨 시나리오는 뒷받침되지 않는 인과 주장을 보류하고 검증된 사실만 보여 줍니다. 연결된 리소스는 Trace 및 Agent Activity 시안과 같은 상관 ID를 사용합니다. |
| 조사 | `mocks/ui/fixtures/adaptive/`의 픽스처 8개 | [조사 형태](#조사-형태)에서 설명하는 절차형 형태입니다. |
| 인시던트 | 열린 인시던트, 서비스 준비 상태 | 운영 요약입니다. 참조 줄과 제목, 기록된 상태, 사실 표, 명시적인 미확인 사항, 접힌 기록 타임라인, 읽기 전용 다음 단계로 구성됩니다. |
| 변경 | 통제된 제안, 효과 검증, 취소 | 7가지 안전장치가 있는 타입 요청 초안, 독립적인 읽기로 확인한 효과, 대화 상태로 한정된 취소 증적입니다. |
| 메모리와 문서 | 메모리 보존, Markdown 문서 | 동의가 필요한 보존 요청과, 통제된 입력으로 렌더링한 문서 및 그 Markdown 원문입니다. |

구조화된 답변 블록은 본문 뒤에 오는 부분입니다. 요약 머리글, 기록된 상태 줄, 사실 표, 근거 상태
그룹(검증됨, 사용 불가, 주장하지 않음), 캡션이 있는 표, 순서가 있는 단계, 접힌 타임라인, 다음 안전
단계, 요청 카드, 렌더링된 문서가 여기에 속합니다. 제안이나 보존 요청은 하나의 제한된 작업 단위이므로
답변 안에서 유일하게 카드로 표시합니다. 그 제어는 별도의 미리 보기 요청을 시작하며, 막힌 제어는 그
이유를 바로 옆에 표시합니다. 형태에 타입 표시 프로필이 있으면 모든 실행 기록이 `governed_proposal`이나
`operational_brief` 같은 프로필 이름을 기록합니다.

이 형태들은 권한을 드러냅니다.

- 제안은 7가지 안전장치가 모두 준비되기 전까지 제출할 수 없으며, 승인된 변경은 별도의 실행기
  신원이 적용합니다.
- 효과 검증에는 독립적인 관찰이 필요합니다. 실행기의 발송 증적은 프로바이더가 요청을 받았다는
  사실만 보여 줍니다.
- 취소는 운영자 자신의 재개 가능한 대화 작업만 바꾸며, 실행 기록은 그 권한을 `read`가 아닌
  이름으로 표시합니다.
- 메모리는 동의한 뒤에만 보존합니다. 원시 로그, 비밀 값, 임시 상태, 검증되지 않은 주장은 제외합니다.

## 작업 공간 틀

이 시안은 Console 틀 프리미티브로 대화를 감쌉니다. 머리글에는 검색, 새 대화, 대화 목록, 덱이 보는
내용, 닫기가 있습니다. 대화 목록은 기록 패널을 여는데, 이 패널은 형태마다 대화 하나를 현재 화면과
다른 화면으로 나누어 보여 주며 필터로 좁힐 수 있습니다. 현재 대화를 고르면 다시 재생하고, 다른
대화를 고르면 해당 형태로 페이지를 다시 엽니다. 덱이 보는 내용은 입력창의 참조 칩이 새 질문에 더하는
참조 화면, 관찰 시각, 새로 고침 동작을 보여 줍니다.

뷰포트가 1,100 px 이하이면 공통 프리미티브가 기록 패널을 가림막이 있는 오버레이로 바꾸고 맥락
패널을 숨깁니다. Escape 키와 가림막으로 오버레이를 닫으며, 포커스는 머리글 제어로 돌아갑니다. 대화
기록, 준비 상태 표시줄, 입력창은 같은 900 px 열과 같은 여백을 공유하므로 질문, 답변, 입력이 같은 두
가장자리에 맞춰 정렬됩니다.

## 재생 동작

이 시안은 준비 계획 전체를 대기 단계로 먼저 표시하고 각 단계의 결과는 그 단계가 실행된 뒤에만
보여 줍니다. 턴이 읽을 행 수에 맞춘 고정 창으로 출처를 읽고, 답변은 단어 단위로 스트리밍하면서
문장이 끝날 때마다 잠시 멈추며, 답변이 나타나기 전에 준비 패널을 접습니다.

대화 기록은 답변 중인 질문을 위쪽 가장자리 밖으로 밀어 올리지 않으면서 새 내용 쪽으로 부드럽게
이동합니다. 턴이 끝나면 검증 행이 보이는 위치까지 이동하고, 운영자가 직접 스크롤하면 즉시
따라가기를 멈추므로 읽고 있는 텍스트가 갑자기 움직이지 않습니다. 스크롤이 맨 아래에 닿으면 대신
가장 새로운 내용을 따라갑니다. 최신으로 이동은 보이는 가장자리 아래에 실제 내용이 있을 때만 입력창
맥락 행의 끝에 나타납니다. Console은 `console/src/deck/scroll-stick.ts`로 같은 규칙을 적용하며,
부드럽게 이동하는 대신 각 목표 위치로 바로 이동합니다.

이 시안은 Console과 같이 모델 추적 캡처 여부를 턴마다 기록합니다. 실행 기록은 해당 턴에서
캡처가 켜져 있었고 설정이 여전히 켜져 있을 때만 요청, 시스템, 응답 다이제스트가 있는 모델
이벤트와 프로바이더 호출 행을 표시합니다. 설정을 켜더라도 캡처하지 않은 턴의 프로바이더
데이터는 드러나지 않습니다. 재생된 턴은 실행 기록의 합성 일정을 실제로 관찰한 단계 시각에
맞추므로, 기록된 소요 시간이 화면에 보인 과정과 일치합니다.

## 조사 형태

절차형 조사는 작업 과정을 접어 없애지 않고 대화 기록에 남깁니다. 밀도는
[작업 진행 계약](operator-console-progressive-conversations-ko.md#작업-진행-계약)이 정한 대로 타입
기반 궤적에서 정하며 답변 문장으로 정하지 않습니다. 시안은 다음 역할을 렌더링합니다.

- **계획.** 컴파일러가 세운 계획을 한 줄로, 그 계획이 설명하는 작업 위에 보여 줍니다.
- **웨이브.** 계획된 웨이브마다 한 행이 있고, 행마다 상태 표시가 하나 있습니다. 표시는 웨이브 번호,
  스피너, 결과 순으로 바뀝니다. 한 웨이브의 읽기는 병렬 레인으로 실행되며, 다음 웨이브는 현재
  웨이브가 끝난 뒤에만 시작합니다. 끝난 웨이브는 한 줄 요약으로 접혀서 다음 웨이브가 진행되는 동안
  대화 기록이 차분하게 유지됩니다. 결정론적 비교가 계획되어 있으면 마지막 행으로 이어집니다.
- **활동 카드.** 각 읽기는 라벨, 종류, 상태, 소요 시간을 보여 줍니다. 상세에는 작업, 권한 확인 결과,
  근거 권한, 실행 권한 없음, 대상 식별 정보, 도구를 보여 준 뒤, 타입 호출과 가려진 프로바이더 표현을
  간결한 코드 블록으로 보여 주고, 출력 또는 출력이 없는 이유를 보여 줍니다. 상세는 읽기가 끝난 뒤에만
  렌더링합니다.
- **작업 흐름 마일스톤.** 각 웨이브가 끝난 뒤의 결정론적 진행 사실입니다. 답변 텍스트와 다르게
  표시하며 근거 주장을 담지 않습니다. 각 마일스톤은 조용한 한 줄로 표시하며, "Progress" 라벨은
  보조 기술용으로만 남깁니다.
- **한도.** 턴이 진행되는 동안에는 정책 한도를 보여 줍니다. 턴이 끝나면 서버가 보고한 최대치 대비
  사용량 계측으로 바꿉니다. 시안은 남은 예산을 실시간 막대로 그리지 않습니다.
- **맥락 영수증.** 적용된 운영자 선호를 접힌 영수증으로 보여 주며, 근거나 지시가 아닌 맥락이라고
  표시합니다.

답변은 발견 사항을 먼저 말하고, 사실 표, 확인 항목별 한 줄, 한계가 있으면 근거 한계 안내, 그리고
다음 안전 단계를 차례로 보여 줍니다. 중지하면 끝난 읽기는 모두 남기고, 실행 중인 읽기는 중지됨으로,
시작하지 않은 웨이브는 시작 안 함으로 표시하며, 답변은 작성하지 않습니다. 추천 후속 질문은 새 요청을
시작합니다.

시안의 조사 시나리오는 차이 없음, 차이 발견, 시간 초과된 읽기, 근거 충돌, 권한 거부, 같은 수준의
후보 사이 확인 질문, 오래된 맥락, 예산 소진을 다룹니다. 차이를 발견하면 초안을 만들지 않고 수정 초안
작성을 별도 요청으로 제안합니다. 시나리오는 `mocks/ui/fixtures/adaptive/`의 합성 궤적을 읽으며,
Console 계약 테스트도 같은 파일을 파싱합니다.

## 코드 블록

실행 기록의 페이로드는 컴포넌트 갤러리의 간결한 코드 형태를 사용합니다. 어두운 코드 배경,
Copy가 있는 언어 라벨, 문법 색상으로 구성됩니다. 색상은 `ui/calm-slate-tokens.css`의 공통
`--cs-code-*` 토큰에서 가져오며 갤러리도 같은 토큰을 읽습니다. Copy는 원문을 그대로 복사합니다.
Console은 답변 코드와 생성된 코드 근거에도 같은 형태를 사용합니다. 문법 강조기의 토큰 클래스는
공통 토큰에 연결되며, 일반 텍스트는 문법을 추측해 강조하지 않습니다.

턴에서 추적 캡처가 켜져 있으면 각 모델 호출의 동적 시스템 프롬프트에서 공개 합성 프롬프트 픽스처
`mocks/ui/assets/prompts/system-prompt.example.md`도 열 수 있습니다. 이 파일은 그 자리에서 읽기 전용
Markdown으로 열리며 Copy와 Download를 제공하고, 5초 기한 안에 불러오며, 불러오기에 실패하면 그
사실을 명시합니다. 파일을 닫으면 진행 중인 불러오기를 취소합니다. 이 픽스처는 캡처한 런타임
프롬프트가 아닙니다.

## 화면 이동 동의

출처를 선택하면 대화를 벗어나지 않고 그 자리에서 출처 정보를 펼칩니다. 출처의 열기 동작과 근거
원본 표시줄을 포함해 다른 화면으로 이동하는 deck 링크는 모두 먼저 확인 대화 상자로 운영자에게
묻고, 동의한 경우에만 이동합니다. 페이지 안 앵커, 새 탭 클릭, 파일 다운로드는 가로채지 않습니다.
Console에서 도킹하거나 전체 작업 공간으로 연 대화는 경로가 바뀌면 닫히므로 링크가 먼저 묻습니다.
떠 있는 배치는 경로가 바뀌어도 대화를 열어 두므로 링크가 바로 이동합니다.
