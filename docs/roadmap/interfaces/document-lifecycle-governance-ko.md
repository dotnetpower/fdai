# 문서 수명 주기 거버넌스

이 문서는 FDAI가 임시 업로드를 자동 정리하고, 검토된 콘텐츠를 통제된 지식으로 승격하며,
모든 파생 산출물을 추적하고, 저장소와 인덱스 전체의 삭제를 검증하는 방법을 정의합니다.

> **범위:** 보존 기간, 할당량, 공개 대상, 법적 보존 정책은 배포가 소유하는 값입니다.
> 업스트림 저장소는 타입이 지정된 상태, 안전성 불변 조건, 공급자 연결부만 정의합니다.

## 설계 개요

모든 원본은 명시적 처리 등급으로 시작합니다. 임시 콘텐츠는 범위 안에서만 사용하고,
사람이 새로운 불변 통제 버전으로 승격하지 않으면 만료됩니다. 삭제는 가시성을 먼저
차단하고 계보에 연결된 모든 산출물을 정리한 뒤 독립적인 잔존 데이터 없음 검증으로 끝납니다.

## 설계 수정

**초기 설계.** 채팅 첨부에 TTL을 적용하고 지식 문서를 보존하며 벡터와 OCR 출력을 연쇄
물리 삭제합니다.

**비판.** TTL만으로는 활성 대화, 인용, 법적 보존, 프로세스 손실을 처리하지 못합니다.
두 보존 등급으로는 초안과 규제 증거를 표현할 수 없습니다. tombstone 전에 물리 삭제하면
검색 경합이 생기며 참조 횟수만으로는 장애로 생성된 고아 데이터를 찾지 못합니다.
PDF 이미지를 항상 보존하면 비용과 개인정보 노출도 증가합니다.

**수정된 설계.** 처리 등급, 콘텐츠, 인덱스, 보존, 가용성 축을 독립적으로 사용합니다.
임시 콘텐츠에는 범위가 제한된 임대를 적용하고, 승격 시 새 불변 버전을 만들며, 파생물을
콘텐츠 주소 기반 산출물 그래프로 표현합니다. 정리 전에 tombstone 처리하고 영속 정리
효과, 범위가 제한된 표시 후 정리 조정기, 독립 삭제 증적을 결합합니다.

## 독립 수명 주기 축

| 축 | 값 |
|----|----|
| 처리 등급 | `session_ephemeral`, `workspace_draft`, `governed_knowledge`, `regulated_record` |
| 콘텐츠 | 기존 `DocumentState` 업로드, 검사, 추출, 준비, 실패, 삭제 상태 |
| 인덱스 | `not_requested`, `queued`, `building`, `active`, `tombstoned`, `purged`, `failed` |
| 보존 | `live`, `expiring`, `held`, `tombstoned`, `purge_pending`, `purged` |
| 가용성 | 정리 전에 닫히는 기존 `active` 및 `available` 플래그 |

검색에는 활성 상태이고 사용 가능하며 `index_state = active`, `retention_state = live`,
범위 일치, 현재 접근 권한을 모두 만족하는 버전만 포함합니다.

## 처리 등급과 보존

| 처리 등급 | 용도 | 기본 범위 | 승격 |
|----------|------|-----------|------|
| `session_ephemeral` | 채팅 첨부 또는 테스트 업로드 | 사용자 및 대화 | 명시적 사람 요청 |
| `workspace_draft` | 검토 대기 팀 초안 | 작업 영역 컬렉션 | 검토된 컬렉션 요청 |
| `governed_knowledge` | 재사용 지식 원본 | 컬렉션 정책 | 이미 통제됨 |
| `regulated_record` | 감사, 법무, 승인 증거 | 제한 전용 컬렉션 | 별도 규제 워크플로 |

배포는 유휴 임대와 최대 수명으로 임시 만료를 계산합니다. 읽기는 최대 수명을 연장하지
않습니다. 법적 보존은 보존 상태를 `held`로 바꾸고 원본, 파생물, 인덱스, 캐시, 백업
삭제를 차단합니다. 사용자, 대화, 컬렉션, 저장 바이트, OCR 페이지, 임베딩 수별 할당량을
적용합니다.

## 승격

승격은 임시 레코드를 영구 지식으로 직접 변경하지 않습니다.

1. 현재 행위자, 대상 컬렉션, 공개 대상, 용도, 분류, 보존을 다시 확인합니다.
2. 원본 다이제스트, 맬웨어, 보호, 추출 근거를 다시 검증합니다.
3. 임시 원본 계보를 가진 새 불변 통제 문서 버전을 만듭니다.
4. 같은 테넌트, 컬렉션, 접근 서술자, 보존 경계 안에서만 바이트를 재사용합니다.
5. 정책과 필요한 사람 검토 증적이 영속화된 뒤 통제 인덱스를 활성화합니다.
6. 대화가 만료될 때까지 임시 인용을 보존하며 근거를 자동으로 바꾸지 않습니다.

## 산출물 그래프

`DocumentArtifactManifest`는 각 파생 객체를 문서 버전과 원본 다이제스트에 연결합니다.
원본, 네이티브 텍스트, 페이지 래스터, 포함 이미지, OCR 텍스트, 썸네일, 정규화 묶음,
청크, 임베딩을 표현합니다. 보존 항목에는 부모, 다이제스트, 위치, 미디어 형식, 크기,
보존 기한, 저장 상태를 기록합니다.

PDF와 Office 추출은 다음 규칙을 따릅니다.

- 네이티브 텍스트를 먼저 추출하고 페이지를 텍스트, 이미지, 혼합으로 분류합니다.
- 필요한 페이지만 래스터화하고 OCR합니다.
- 승인된 멀티모달 용도에 필요한 래스터와 포함 이미지만 보존합니다.
- 짧은 캐시 임대를 적용한 요청 시 썸네일을 우선합니다.
- 중간 이미지를 버려도 계보와 추출기 버전을 기록합니다.
- 페이지, 픽셀, 바이트, 단위, 문자, CPU, 메모리, 경과 시간 제한을 적용합니다.

## Tombstone, 정리, 검증

삭제와 만료는 세 단계로 처리합니다.

1. **Tombstone:** 가용성을 false로 바꾸고 인덱스 및 보존 상태를 tombstone으로 원자 변경합니다.
2. **수렴:** 영속 멱등 효과로 청크, 임베딩, OCR 텍스트, 묶음, 래스터, 이미지, 썸네일,
   캐시, 권한 부여, 정책이 허용한 원본 바이트를 삭제합니다.
3. **검증:** 모든 소유 저장소를 독립 조회하고 삭제 증적을 만듭니다. 활성 인덱스 행,
   파생물, 원본, 캐시가 모두 0이고 법적 또는 백업 차단 사유가 없어야 `purged`가 됩니다.

조정기는 현재 버전, 대화, 인용, 커넥터 포인터, 대기 작업, 보존을 활성 root로 표시합니다.
참조 없는 산출물을 복구 유예 상태로 옮긴 뒤 말단부터 정리합니다. 참조 횟수는 최적화에
사용하지만 표시 후 정리 복구를 대체하지 않습니다.

## Console 계약

채팅 기본값은 **이 대화에서만 사용**입니다. 운영자는 **작업 영역 초안으로 보관** 또는
**통제된 지식에 추가**를 선택할 수 있으며 지식 추가에는 컬렉션과 공개 대상 확인이
필요합니다. 문서 화면은 처리 등급, 만료, 인덱스 증적, 파생물 저장량, 승격, tombstone,
정리 진행률, 물리 삭제를 지연하는 보존을 표시합니다.

## Release 게이트

- 만료되거나 tombstone 처리된 콘텐츠는 검색에 들어가지 않습니다.
- 모든 보존 파생물은 완전한 부모 계보와 상속된 접근 및 보존을 가집니다.
- 정리 단계 사이에서 프로세스가 종료되어도 재시작 후 수렴합니다.
- 법적 보존은 모든 물리 삭제를 차단합니다.
- 잔존 데이터나 차단 사유가 있으면 삭제 증적은 통과할 수 없습니다.
- 컬렉션 간 중복 제거와 존재 정보 공개는 계속 허용하지 않습니다.
- 지표는 임시 바이트 증가, 승격률, 고아율, 삭제 지연, 잔존 데이터를 보여 줍니다.
