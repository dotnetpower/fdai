# Live 화면 지표

이 문서는 Live 화면의 측정 구간과 각 지표의 분모를 정의합니다.
소스 읽기나 연결 상태를 실행으로 오해하지 않고, 수신된 운영 활동과 제어 루프 결정을
구분할 수 있습니다.

> **경계:** 이 브라우저 측정은 실행 권한을 부여하거나 런타임 준비 상태를 증명하지 않습니다.
> 명시적인 Sample 표시는 실제로 관측된 Live 데이터와 구분합니다.

## 설계 개요

중앙 SSE에서 해석된 활동 메시지를 받습니다. 브라우저는 중복을 제거하고 원래 이벤트 시각을
유지하며, 화면에 보이는 카드 수와 독립적으로 최근 60초 구간을 요약합니다.

| 지표 | 포함하는 관측 | 제외하는 관측 |
|------|---------------|---------------|
| 초당 이벤트 | 중복되지 않은 제어 루프 단계 및 소스 읽기 활동 메시지 | 연결 유지 신호, 연결 정보, 중복 재전송 |
| 게이트 구성 | 이벤트별로 한 번씩 집계한 명시적 제어 루프 결정 | 게이트 결정이 없는 소스 읽기 |
| 티어 구성 | 이벤트별로 한 번씩 집계한 명시적 제어 루프 티어 배정 | 티어 배정이 없는 소스 읽기 |

## 측정 구간

최근 스냅샷은 원래 관찰 시각을 유지합니다. 오래된 스냅샷은 카드에 표시되어도 현재 처리량을
늘리지 않습니다. 처리량 차트는 제어 루프 메시지와 소스 읽기를 구분하며, 초당 발생 건수는
소수점 둘째 자리까지 표시합니다.

게이트와 티어 구성은 감사 완료를 기다리지 않고 명시적인 결정이나 티어가 관측되면
갱신됩니다. 같은 사실이 다시 전달되어도 60초 구간을 다시 시작하지 않습니다. 분포가 비어
있으면 결정이나 배정이 관측되지 않았다고 표시하며, 소스 읽기가 승인되었다는 뜻이 아닙니다.

각 측정 모음은 최대 10,000개 항목을 보존합니다. 한도 초과로 제외된 측정, 잘못된 이벤트
시각, 전송 누락 또는 커서 초기화가 있으면 불완전한 구간임을 명시합니다. 화면을 고정하면
표시된 측정값을 유지하며, 범위가 제한된 수집기는 계속 메시지를 받습니다.
