# 도표를 포함한 WARA 설명

WARA 설명은 원본과 결속된 본문, 검토한 그림 또는 직접 작성한 관계 도표로 권고의 목적, 적용 조건, 구성,
검증 방법을 안내합니다. 평가 카탈로그를 보완하지만 발견 결과, 승인, 승격, 실행 결정을
바꾸지는 않습니다.

> **범위:** 수명 주기 권고 456개 전체를 기록합니다. 활성 393개는 기술 안내를 제공하고,
> 비활성 63개는 이력임을 명확히 표시합니다. 구성 예시는 설치 환경의 관찰 결과가 아니며
> 충족 상태를 의미하지 않습니다.

## 설계 요약

1. 결정적인 콘텐츠 빌드는 고정된 APRL ID와 설명을 검토된 서비스·컨트롤 안내 및 권고별
   의미와 결합합니다.
2. 구현을 포함하지 않는 공통 패키지는 엄격한 표시 계약과 생성된 공용 코퍼스를 제공합니다.
   상세 읽기는 ID, 수명 주기, 원본 고정 값을 검증한 뒤 설명 하나를 연결합니다. 목록 읽기는
   전체 도표 코퍼스를 전달하지 않습니다.
3. Console은 범위가 제한된 형식화된 텍스트, 구성 비교 목록, 방향이 있는 도표를 표시합니다.
   평가와 출처 메타데이터는 별도로 유지하고 누락, 차단, 사용 불가를 명시합니다.

실행 중 모델 호출, 공급자 요청, 외부 이미지 다운로드, 고객 파일 처리는 없습니다.
검토한 공식 참고 이미지는 콘텐츠 작성 시 패키지에 포함할 수 있습니다. 상세 읽기나
내보내기 중 임의 URL에서 이미지를 가져오지 않습니다.

## 콘텐츠와 그림 개선

전체 코퍼스의 독자용 텍스트는 한국어로 완성해야 합니다. 영어 문장을 한국어 제목으로
감싸는 것으로 대체하지 않습니다. 출처의 원문 제목, 공식 제품명, 고정 식별자는
원래 표기를 유지할 수 있습니다. 빌드 단계의 누락 검사는 기술·문장 검토와 구분합니다.

각 GUID의 초점과 확인 항목은 `controls-ko.tsv`에, 출처를 고정한 독자용 재정의는
`reader-text-ko.json`에 작성합니다. 공통 원리와 조건부 도식의 번역은 해당 생성기
옆에 둡니다. 오프라인 빌드는 번역 누락과 영어 문장을 한국어로 감싼 표현을 검사하고
통과한 경우에만 분할 파일을 기록합니다. 범위 증적에는 번역 입력과 그림 선택 결과를
포함합니다. 목록 제목은 원문 제목임을 명시합니다.

정확한 파일, 출처와 재사용 조건을 검토한 관련 공식 그림을 우선합니다. 원본 비율,
그림 내부의 원문 언어 안내, 한국어·영어 캡션과 대체 텍스트를 유지합니다. 패키지에
포함하는 이미지는 다이제스트, 출처 문서, 이미지 URL, 저작자 표시, 라이선스를 함께
기록합니다. 임의 이미지 URL, 실행 가능한 SVG, 실행 중 다운로드, 요청자가 선택한
파일 경로는 지원하지 않습니다. JSON, Console, 인쇄와 프레젠테이션 출력에서도
같은 출처 표시를 보존합니다.

각 권고에 그림 선택 결과를 기록합니다. 직접 그리는 경우 검토를 마친 적합한 자산이
없거나, 권고 범위와 다르거나, 읽기 어렵다는 구체적인 이유가 필요합니다. 문서를
검토하지 않았다는 사실로 공식 그림이 없다고 단정하지 않습니다. 공식 그림의
의미를 수정하기보다 필요한 설명을 별도로 보충합니다. VM 백업에서는 확장 기반 방식과
에이전트 없는 일관성 방식, 임시 디스크 제외, 스냅샷 전송, Recovery Services vault
보존과 복원 검증을 구분합니다.

`reference-images.json`은 문서 점검, 후보 탐색, 시각적 적합성, 자산별 재배포 권리
검토를 구분합니다. 발견한 그림이 승인된 자산인 것은 아닙니다. 권리가 미확정이면
깨지거나 승인되지 않은 이미지를 연결하지 않고 직접 작성한 도식을 유지합니다.
자산 경로는 검토한 최대 2 MiB의 콘텐츠 주소 기반 PNG를 받아 패키지와 Console
복사본을 모두 검증합니다. 합성 이미지 테스트는 전송과 내보내기 동작만 검증하며
Microsoft 그림의 사용 승인을 뜻하지 않습니다.

설명 16개는 Learn의 공식 PNG를 변경하지 않고 Console 정적 자산과 공유 내보내기 패키지에
포함합니다. VM 백업 이미지의 검토 기록에는 공개 문서의 소스 경로, 저장소의 CC BY 4.0 고지,
확장 기반 백업이라는 그림의 설명 범위를 남깁니다. 나머지 15개는
`reference-image-reviews.json`에 기록합니다. 각 항목은 권고, 인용된 정확한 문서와 이미지,
시각 검토 뒤에 작성한 한영 대체 텍스트와 캡션을 담습니다.
`scripts/catalog/wara_guidance_image_selection.py --fetch`는 결정마다 공개 근거를 수집하며,
다음 조건을 모두 확인하지 못하면 이미지를 포함하지 않습니다. Learn 문서가 공개 Microsoft Docs
소스 저장소와 게시 리비전을 밝혀야 하고, 해당 저장소의 라이선스와 고지가 콘텐츠를
CC BY 4.0으로 허용해야 하며, 저장소에 바이트가 동일한 이미지가 있어야 합니다.
매니페스트에는 리비전, 저장소 경로, 다이제스트, 사용 범위를 기록합니다.
제3자 제품 표시가 보이는 이미지는 승인하지 않습니다.
화면의 출처 링크는 이미지 파일이 아닌 해당 이미지를 포함한 문서를 엽니다.
화면을 표시할 때 외부 이미지를 요청하지 않습니다. 원본 이미지의 영어 표시는 유지하고
한국어 대체 텍스트, 캡션, 언어 안내를 제공합니다. 이 선택이 나머지 권고 440개의
이미지 사용 승인을 뜻하지는 않습니다. 목록을 갱신해도 검토한 선택은 유지하지만,
프레임워크 리비전이나 정확한 인용 문서가 달라지면 다시 검토합니다.

직접 작성하는 도식은 읽기 순서, 분리한 곡선 경로와 명시적인 관계 설명을 사용합니다.
노드 침범 여부만으로 통과를 판단하지 않습니다. 경로, 교차, 겹치는 구간, 관계 문구의
대응과 한영 가독성을 함께 확인합니다. 데스크톱 검증을 먼저 통과한 뒤 좁은 화면과
모바일을 검증합니다. 인증된 실제 화면을 확인하지 못한 경우에는 그 제약을 명시합니다.

## 콘텐츠 계약

모든 설명은 다음을 포함합니다.

- 정확한 APRL 권고 ID, 원본 리비전, 원본 다이제스트, 수명 주기.
- 제목, 요약, 기대 효과, 동작 원리 설명.
- 적용 대상과 제외 조건, 예시로 표시한 변경 전후 구성.
- 구현 단계, 검증 단계, 주의 사항.
- 형식화된 도표 노드, 방향이 있는 연결선, 레이블, 캡션, 텍스트 대안.
- 공개 APRL 및 Microsoft Learn 출처.
- 위 필드 전체를 포함하는 콘텐츠 다이제스트.

작성한 코퍼스의 독자용 텍스트는 영어 원문과 완전한 한국어 번역을 제공합니다.
전송 계약은 이전 레코드를 위해 영어 대체 표시를 유지하지만 번역 완료 근거로 사용하지 않습니다.
기계 ID, 다이제스트, 직렬화된 토큰은 언어에 따라 바뀌지 않습니다.
권고별 원본 의미가 재사용하는 유형별 그림보다 우선합니다.
제목이나 공통 그림만으로 충분한 설명을 제공했다고 판단하지 않습니다.
도식이 실제 관측 결과가 아닌 구성 예시라는 안내는 도식 설명에 두고 각 노드에서 반복하지
않습니다. 노드 설명에는 원본 도식의 연결 대상과 관계를 표시하며, 근거 노드는 해당 권고의
구체적인 확인 절차를 유지합니다.

코퍼스는 ID 456개를 정확히 한 번씩 기록하고 활성·비활성 393/63개, 정확한 원본 리비전,
전체 및 항목별 다이제스트를 검증합니다. 필수 설명 누락, 연결되지 않은 도표 노드,
알 수 없는 연결선 끝점, 중복 ID, 검토되지 않은 문서 원본은 명시적으로 실패합니다.
설치된 코퍼스는 수 MiB의 단일 소스 파일 대신 다이제스트로 결속된 매니페스트와 범위가
제한된 조각 파일을 사용합니다. 조각별 상한은 512 KiB, 전체 읽기 상한은 8 MiB입니다.
GUID 검사는 지정된 작성·생성·회귀 검사 경로에서 독립적으로 고정된 공개 APRL 카탈로그의
정확한 ID만 수락합니다. 알 수 없는 GUID나 변경된 원본 고정 값은 계속 실패합니다.

## 표현 수용 기준

범위를 제한한 수용 기준에는 다음 세 권고가 있습니다.

| 권고 | 반드시 구분할 내용 |
|------|--------------------|
| Private DNS 다중 지역 VNet 링크 | 지역별 연결은 VM 자동 등록이 아닙니다. 이름 해석 성공은 백엔드 정상 상태나 장애 조치를 증명하지 않습니다. |
| Dedicated/Isolated VM 유지 관리 | Host, OS image, Guest 범위를 구분합니다. 기준 영향도 Medium과 자동 평가 보류 상태를 유지합니다. |
| 지역별 AI 서비스 복원력 | 통제된 게이트웨이, 기본·대체 배포, 명시적인 라우팅 선행 조건을 표시합니다. Regional, Data Zone, Global 배포 표시가 같은 처리 위치나 자동 장애 조치를 의미하지 않습니다. |

비공개로 확인한 발표 자료는 정보 계층의 기준일 뿐 공용 콘텐츠가 아닙니다. 고객 화면,
환경별 수량, 배포 이름, 근거가 없는 주장은 제외합니다. 발표 자료의 무관한 인용은
그대로 옮기지 않고 공식 근거로 바로잡습니다.

수용 화면은 필요한 이유를 설명하고 해당 관계를 도표로 보여주며 예시 구성과 현재 평가를
구분하고 조치, 검증, 정확한 공개 출처를 제공합니다. 작은 글자, 겹치는 연결선,
일반적인 "규칙 -> 검사 -> 통과" 상자로만 만든 그림은 이 기준을 충족하지 않습니다.

읽기 흐름은 중복된 요약 제목 없이 권고 제목, 요약, 기대 효과, 그림 순서로 구성합니다.
본문은 읽기 쉬운 너비로 제한하고 그림은 더 넓은 공간을 사용합니다.
상세 화면이 넓으면 요약 옆에 페이지 내 이동 목록을, 공식 이미지 옆에 설명 범위와 출처를,
관련된 절은 나란히 배치합니다. 화면이 좁으면 모두 읽는 순서대로 세로로 배치합니다.
공식 이미지는 대체 텍스트와 별도로 표시한 설명 범위·제한을 제공하고,
원본 문서와 라이선스 링크를 항상 표시합니다. 전체 저작자 고지는 펼쳐서 확인할 수 있으며
인쇄에도 포함합니다. 브라우저 기본 대화 상자에서 변경하지 않은 이미지를 원본 크기로
확대하고, 좁은 화면에서는 키보드로 이미지 영역을 스크롤할 수 있습니다.
Escape를 누르면 확대 보기만 닫고 확대 버튼으로 포커스를 돌려줍니다.
권고 상세 화면은 열린 상태를 유지하며, 설명용 가이드와 실제 환경 평가는 구분합니다.

한국어에서는 권고 목록과 행 동작 레이블에 설명의 한국어 제목을 표시하고 원문 제목은 툴팁과 검색에 유지합니다. Operator는 컨트롤의 리비전, 다이제스트, 수명 주기가 패키지된 설명과 일치할 때만 한국어 제목을 붙이고, 설명을 사용할 수 없으면 붙이지 않습니다.

문서 본문은 Console 글자 크기 체계를 따릅니다. 제목은 24px, 요약과 절 제목은 16px, 본문은 14px이며
12px보다 작은 글자는 사용하지 않습니다. 도식 범례는 실제로 그려진 관계 유형의 이름을 표시하고,
조건부 관계가 있는 도식에만 조건부 유형을 표시하며, 화살표 옆 번호가 번호별 연결 관계와 같음을
설명합니다. 연결선은 다른 노드를 가리지 않는 가장 짧은 경로의 부드러운 곡선입니다. 인접한 노드는
직접 연결하고, 노드가 가로막으면 그 노드의 바로 위나 아래로 돌아갑니다. 한국어는 단어 단위로
줄을 바꾸며 요약은 영어보다 넓은 너비를 사용합니다. 변경 전과 후는 독립된 목록입니다.
배열에서 같은 순서에 있다는 이유로 항목을 같은 비교 행에 배치하지 않습니다.
설계 근거는 접지 않고 적용 조건 옆에 표시하며 인쇄에도 포함합니다. 이미지 대체 텍스트를
별도의 화면 캡션으로 반복하지 않습니다. 긴 도식 설명은 연결된 전체 설명으로 옮기되,
원문은 줄이지 않습니다. 절 이동 링크는 선택한 권고 URL을 변경하지 않고 키보드
포커스를 옮깁니다. 이미지 버튼 높이는 데스크톱에서 32px, 좁은 화면에서 44px입니다.
알려진 평가 제한과 근거 담당 역할은 현지화된 문구로 표시하고, 일 단위로 나누어지는
최신성 상한은 일수로 표시합니다. 원시 근거 계약은 기술 정보에 보존합니다.
알 수 없는 코드는 임의로 해석하거나 누락하지 않고 그대로 표시합니다.

## 고객 정보와 자산 경계

공용 코퍼스에는 발표 파일, 고객 화면, 고객 리소스 ID, 비공개 엔드포인트, 계정,
환경별 수량, 고객에게서 파생한 결과를 포함하지 않습니다. 예시는 일반적인 역할 이름을
사용하고 예시임을 명시합니다.

직접 작성한 도표는 저장소의 노드·연결선 데이터입니다. 렌더러는 임의의 SVG, HTML,
JavaScript, 문서가 제공한 이미지 URL, 원격 엔드포인트를 받지 않습니다. 패키지에 포함하는
참고 자산에는 개별 사용 권한, 저작자 표시, 내용 다이제스트, 고객 정보 검토가 필요합니다.
Microsoft Learn에서 공개적으로 접근할 수 있다는 사실만으로 재배포를 허용하지 않습니다.

링크는 원본 APRL, Microsoft Learn 또는 정확히 검토한 Citrix 관리형 서비스 한도 페이지의
범위가 제한된 HTTPS 참조입니다. 공급업체 예외는 원본·경로 하나이며 공급업체 콘텐츠 전체를
허용하지 않습니다. 사용자 자격 증명이나 임의의 원본은 포함할 수 없습니다. 공식 문서가
바뀌면 콘텐츠를 검토하며 권고의 평가 의미를 조용히 바꾸지 않습니다.

## 읽기 경로와 호환성

공통 패키지는 요청자가 지정한 경로가 아니라 설치된 불변 카탈로그를 읽습니다.
`GET /wara-controls/{recommendation_id}`는 저장된 컨트롤의 원본 리비전, 다이제스트,
수명 주기를 검증한 뒤 일치하는 설명 하나만 연결합니다. 불일치는 사용 불가나 오류로
표시합니다. 미작성 또는 이전 권고는 기존 설명과 출처를 유지하고 상세 설명 부재를 명시합니다.
상세 응답 리비전은 저장된 카탈로그 리비전과 선택한 설명의 내용 다이제스트를 함께 결속합니다.
공용 설명만 갱신해도 평가 결과를 바꾸지 않고 캐시 ID가 달라집니다. 설명 다이제스트로
권위 있는 카탈로그 리비전의 누락을 숨길 수는 없습니다.

공통 계약은 Core나 Operator 구현을 가져올 수 없습니다. Core가 평가를 계속 소유합니다.
Operator 읽기 결과와 Console은 본문, 도표, 제품 그룹 검증 표시, 원본 사용 가능 여부에서
적용 여부, 충족, 권한을 도출하지 않습니다.

기존 필터, 페이지 이동, 선택한 권고, 직접 링크, 브라우저 이력이 탐색 기준으로 유지됩니다.
텍스트 필터 밖에서 선택한 GUID가 다른 설명으로 연결되면 안 됩니다. 목록 읽기는 상한을
유지하고 모든 설명을 포함하지 않습니다.

## 공용 발표 자료 내보내기

`scripts/catalog/export_wara_guidance.py`는 선택한 ID 또는 명시적으로 요청한 `--all`
코퍼스를 공용 JSON과 PPTX로 내보냅니다. 설치 환경 근거나 고객 콘텐츠는 읽지 않습니다.
순수한 Core 보고서 생성기는 같은 공통 설명을 사용하며 delivery 어댑터는 기본 벡터 노드와
연결선을 그리고 본문을 18포인트 이상으로 나눠 표시합니다.

출력은 설명의 내용·원본 다이제스트, 수명 주기, 전체 연결 설명과 인용을 유지합니다.
비활성 권고에는 이력 경고를 표시합니다. 기존 비공개 평가 출력은 별도 동작을 유지하며
공용 예시는 범위 다이제스트, 평가 결과, 운영 권한을 얻지 않습니다. Console 인쇄 레이아웃은
공급자나 새 권한 있는 출력 엔드포인트 없이 브라우저의 기본 인쇄/PDF 경로를 지원합니다.

## 렌더링과 검증

도표는 하나의 좌표계와 범위가 제한된 그래프 모양을 사용하며 텍스트 대안을 제공합니다.
모든 연결선은 유효한 끝점을 지정하고 의미가 있는 선 종류에는 레이블을 붙입니다.
색을 해석하지 않아도 읽기 순서를 알 수 있습니다. 긴 ID와 한국어 본문은 문서 폭을
늘리지 않고 줄바꿈합니다.

시각 검증은 데스크톱 1440 x 900부터 수행한 뒤 영향을 받는 상태에 대해 약 993 x 641,
390 x 844를 순서대로 확인합니다. 화면 캡처와 함께 실제 좌표 및 상호작용을 검증합니다.
그림 확대나 전체 보기 기능이 있으면 포커스와 키보드 조작을 유지합니다.

테스트는 원본 ID, 코퍼스 수량, 엄격한 디코딩, 렌더링, 언어별 텍스트, 잘못된 출처,
설명 사용 불가, 권한 없음 동작을 다룹니다. 고정 예제 브라우저 검증은 고정 예제임을
명시하며 인증된 실환경 평가 결과로 표시하지 않습니다.
